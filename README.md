# 🚀 About Me

I'm **Abhinit**, founder and developer of **Xentara**.

Xentara is an ecosystem of streaming platforms, communication tools, AI-powered applications, automation systems, and developer infrastructure.

I enjoy building products from scratch and turning ambitious ideas into real, usable software.

### Current Focus

* 🎬 Expanding **Xstream**

* 🛠 Developer infrastructure and utilities
